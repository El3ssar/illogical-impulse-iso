# The ii-OWNED zsh plugin manifest. `antidote load` (from ~/.zshrc) reads this
# file directly; `iictl plugins` / `iictl shell plugins` add and remove entries

# an upstream-shipped path and not in upstream's rsync --delete set — so shipping
# and editing this file never touches an upstream-owned path. Delete it and the
# guarded `antidote load` in ~/.zshrc no-ops ⇒ vanilla zsh. Contains no PII.
#

#   iictl plugins add antidote <user/repo>      (or: iictl tweak plugins)
